===============================================================================
 LibFights  -  API REFERENCE  (version 1.0.0)
===============================================================================

 Every public function, its parameters and EXACTLY what it returns.

 Conventions
   LF            = the global table LibFights
   f / fight     = a Fight object (see section 9)
   ?             = optional parameter
   -> x          = return value(s), in order
   -> nothing    = returns no values (nil if you read it)
   "ms"          = milliseconds, "sec" = seconds
   Percent values: each field below says its range. "0..1" is a fraction
   (0.52 = 52%), "0..100" is already a percentage.

 IMPORTANT: nothing is logged until Start_Logging() is called. Every other
 lookup (abilities, sets, build, stats, search) works at any time.

 CONTENTS
    1. Logging
    2. Reading fights
    3. Callbacks
    4. Abilities and ability IDs
    5. Sets
    6. Stats
    7. Build reader
    8. Models (predictions)
    9. Fight object methods
   10. Search and queries
   11. Saved data / settings
   12. Text reports
   13. HUD and settings panel
   14. Core helpers
   15. Util helpers
   16. Constants
   17. Data structures returned by the functions above
   18. Internal functions (called by the library, listed for completeness)


===============================================================================
 1. LOGGING
===============================================================================

Start_Logging(options?)                 also LF.Start_Logging / LF.StartLogging
    Registers all combat events and starts collecting fight data. If you are
    already in combat a fight begins immediately.
    options  table, optional. Overrides settings for this logging session only:
             rawEvents, rawEventCap, groupMode, trackTargetEffects, trackPower,
             trackCasts, statSampleMs, combatEndGraceMs, fightTimeoutMs,
             minFightSeconds, modelsEnabled, saveFights, buildDetail
    -> true                              logging started
    -> false, "already logging"          it was already running

Stop_Logging()                          also LF.Stop_Logging / LF.StopLogging
    Ends the current fight and unregisters every event.
    -> true, fight                       fight = the fight that was just ended,
                                         or nil if there was none or it was
                                         discarded (too short / no data)
    -> false, "not logging"

Is_Logging()                            also LF.Is_Logging / LF.IsLogging
    -> boolean

LF.SplitFight()                         also LF.Logger.SplitFight()
    Ends the current fight and immediately starts a new one.
    -> true                              done
    -> false                             not logging

LF.Logger.EndCurrentFight()
    -> true                              a fight was ended and kept
    -> false                             no fight, or it was discarded

LF.Logger.ClearFights()
    Forgets all fights held in memory this session.
    -> nothing

LF.Logger.GetRegisteredEvents()
    -> array of strings                  namespaces of registered events
                                         (empty when not logging)

===============================================================================
 3. CALLBACKS
===============================================================================

LF.RegisterCallback(eventName, callback, arg?)
    -> true                              registered
    -> false                             eventName not a string or callback
                                         not a function

LF.UnregisterCallback(eventName, callback)
    -> nothing

LF.HasListeners(eventName)
    -> boolean

LF.FireCallback(eventName, ...)
    -> nothing                           (only fires when listeners exist)

Callback names (LF.EVENTS.*) and the arguments your callback receives:
    INITIALIZED      ()
    LOGGING_STARTED  (options)                 options table (may be empty)
    LOGGING_STOPPED  ()
    FIGHT_STARTED    (fight)
    FIGHT_ENDED      (fight, reason)           reason: "combatEnd" "timeout"
                                               "stopped" "split" "zone" "manual"
    COMBAT_EVENT     (fight, direction, category, result, abilityId, hitValue,
                      overflow, sourceUnitId, targetUnitId, damageType)
                     direction: 1 out, 2 in, 3 self  (LF.Fight.DIR)
                     category : see 16 (damage heal shield avoid cc ...)
    EFFECT_CHANGED   (fight, scope, changeType, abilityId, effectName,
                      unitId, stackCount)      scope: "player" | "target"
    PROC             (fight, procEntry)        procEntry: see 17.10
    DEATH            (fight, deathEntry)       deathEntry: see 17.14
    CAST             (fight, slotIndex, abilityId, kind)
                     kind: "light" "heavy" "skill" "ultimate" "other"
    BAR_SWAP         (fight, activeWeaponPair) 1 = front, 2 = back
    STATS_SAMPLE     (fight, statSnapshot)     snapshot: see 17.18
    GEAR_CHANGED     (fight | nil, slotIndex)
    SCAN_PROGRESS    (scanProgress)            see 17.3
    SCAN_DONE        (scanProgress)

===============================================================================
 8. MODELS (PREDICTIONS)                             LF.Models.*
===============================================================================

 The models learn while logging. "Reference" targets (target dummies by
 default) calibrate the resistance model. Before that, only relative
 toughness is available.

GetReport()
    -> ModelReport table (17.23)

GetTargetEstimate(targetName)
    -> TargetEstimate table (17.24)
    -> nil                               nothing learned about that target

GetAllTargetEstimates()
    -> array of TargetEstimate           most samples first

GetIncomingDR()
    -> {
         armorMitigationPct  number 0..100   your armor mitigation (smoothed)
         otherDRPct          number 0..100   block / buffs / other DR estimate
         totalDRPct          number 0..100   1 - (1-armor)(1-other)
         samples             number
         otherStdPct         number 0..100   uncertainty of otherDRPct
       }

GetCritEstimate(abilityId?)             nil = all abilities
    (if that ability has no crit data yet, the crit CHANCE fields fall back
     to the overall estimate; the crit DAMAGE fields stay nil)
    -> {
         critChance            0..1      | nil
         critChanceStd         0..1      | nil
         samples               number    | nil   hits observed
         critDamageMultiplier  e.g. 1.75 | nil   needs >= 3 crits and
         critDamagePct         e.g. 75   | nil   >= 3 non-crits on the
         critDamageWeight      number    | nil   same target
       }

PredictHit(abilityId, targetName?)
    -> {
         nonCrit         number   expected non-crit hit
         crit            number   expected crit hit
         average         number   expected hit including crit chance
         critChance      0..1
         critMultiplier  number
         rmse            number   model error (same units as the hit)
       }
    -> nil                               the ability has too little data

PredictIncomingHit(abilityId, damageType)
    -> meanHit, peakHit                  expected / worst hit against your
                                         CURRENT resistances
    -> nil                               ability never seen

GetTTK(unitTag?)                        default "boss1"
    -> secondsRemaining, healthFraction  health falling, enough samples
    -> nil, healthFraction               not falling / under 3 samples
    -> nil                               no data for that unit

GetAllTTK()
    -> array of { unitTag, name, secondsRemaining | nil, healthFraction }

GetDPSForecast(secondsAhead?)           default 1
    -> number | nil                      forecast DPS (nil before any data)

PredictFightOutcome(fight?)             default: current fight
    -> {
         currentDPS, elapsedSec, ttkSec | nil,
         predictedDurationSec | nil, predictedTotalDamage | nil,
         predictedFinalDPS | nil         (the predicted* fields need TTK)
       }
    -> nil                               no fight

IsReferenceTarget(targetName, targetType)
    -> boolean

Reset()                                 -> nothing   forget everything learned
Save()                                  -> nothing   (only if persistModels)
Load()                                  -> nothing   (only if persistModels)
GetState()                              -> internal state table (advanced use)

--- Primitive models (usable on their own) ----------------------------------
Models.NewRLS(nFeatures, lambda?, delta?)   -> RLS
    rls:Predict(x)        -> number               x = array of nFeatures
    rls:Update(x, y)      -> number               prediction error before update
    rls:GetRMSE()         -> number
    fields: w (weights), P, count, mse
Models.NewKalman(q, r)                      -> Kalman
    k:Update(z)           -> number               new estimate
    k:Std()               -> number | nil         nil before the first update
    fields: x (estimate), p (variance), n
Models.NewWelford()                         -> Welford
    w:Add(x)              -> nothing
    w:Variance()          -> number               0 with fewer than 2 values
    w:Std()               -> number
    fields: n, mean
Models.NewBeta(a?, b?)                      -> Beta (defaults 1, 1)
    b:Observe(success)    -> nothing
    b:Mean()              -> number 0..1
    b:Std()               -> number
    b:Count()             -> number               observations
Models.NewTrend(halfLifeSec?)               -> Trend (default 30)
    t:Add(time, value)    -> nothing
    t:Fit()               -> slope, intercept     nil under 3 samples
Models.NewHolt(alpha?, beta?)               -> Holt (defaults 0.3, 0.1)
    h:Update(y)           -> nothing
    h:Forecast(steps?)    -> number | nil

===============================================================================
 10. SEARCH AND QUERIES
===============================================================================

LF.Search(query, opts?)
    query  free text and/or filters:
             in:ability in:set in:fight in:effect in:proc in:target in:stat
             in:cast in:event      (several "in:" allowed; none = all kinds,
                                    except events, which need in:event)
             id:12345              exact ability / set / effect / proc id
             fight:7               search inside fight #7
    opts.limit  default 50
    opts.fight  Fight to search inside (default: current or last fight)
    -> array of SearchResult:
         {
           kind    "ability" "set" "stat" "fight" "target" "fightAbility"
                   "effect" "proc" "cast" "event"
           id      ability id / set id / stat key / fight id / unitId
           name    string
           icon    string ("" if none)
           detail  string  one-line description
           data    the underlying table (AbilityInfo, SetInfo, Fight,
                   TargetRow, aggregate, EffectRow, ProcEntry, cast row,
                   DecodedEvent or the stat value)
         }

LF.SearchFormatResult(result)           also LF.Search_.FormatResult
    -> string                            "[kind] icon name (id) detail"

LF.Search_.Parse(query)
    -> { terms = array, filters = map, kinds = set | nil,
         text = string, ltext = lower-case text }

LF.FindEvents(fight?, filter?)          fight default: last fight
    filter (all optional):
      direction "out"|"in"|"self"|"group"   category (see 16)
      result  abilityId  abilityName (substring)  source  target (substrings)
      sourceUnitId  targetUnitId  damageType  crit (true/false)
      minHit  maxHit  fromMs  toMs (from fight start)
      limit (default 200)  newestFirst (true)
    -> array of DecodedEvent (17.17)     {} when no fight or no raw events

LF.NewQuery(fight?)
    -> Query                             chain the setters, then run it
    Setters (each -> the same Query):
      :Direction(d) :Category(c) :Result(r) :Ability(id) :AbilityName(s)
      :Source(s) :Target(s) :DamageType(dt) :Crit(bool) :MinHit(n)
      :MaxHit(n) :From(ms) :To(ms) :Limit(n) :NewestFirst()
    :Run()     -> array of DecodedEvent
    :Count()   -> number      (no limit unless you set one)
    :Sum()     -> number      sum of hit values
    :Max()     -> DecodedEvent | nil   event with the biggest hit
    example:
      LibFights.NewQuery(f):Direction("out"):Crit(true):MinHit(10000):Count()

LF.QueryFights(filter?)
    filter: zone, title, target, character (substrings), minDurationSec,
            minDPS, sinceTimestamp
    -> array of Fight                    memory first, then saved fights

===============================================================================
 12. TEXT REPORTS                                    LF.Report.*
===============================================================================

 All "...Lines" functions return an ARRAY OF STRINGS ready for chat (with
 color codes and |t icon markup). Print them with LF.PrintLines(lines).
 When the fight is nil they return a one-line message such as "No fight.".

FightSummaryLines(fight)               -> lines   8 lines: all main metrics
AbilityLines(fight, kind?, limit?)     -> lines   kind default "damageOut",
                                                  limit default 10
TargetLines(fight, limit?)             -> lines   limit default 8
EffectLines(fight, scope?, limit?)     -> lines   scope default "player",
                                                  limit default 15
ProcLines(fight, limit?)               -> lines   limit default 15
SetLines(fight)                        -> lines
StatLines(fight?)                      -> lines   fight stats (avg/min/max)
                                                  or the current snapshot
                                                  when fight is nil
PowerLines(fight)                      -> lines
DeathLines(fight)                      -> lines   includes last 5 recap hits
BuildLines(build?)                     -> lines   reads the build if nil
ModelLines(report?)                    -> lines   uses GetReport() if nil
AbilityInfoLines(abilityId)            -> lines
SetInfoLines(setId)                    -> lines
AllFightLines(fight)                   -> lines   every report above combined

ShortLiveText(fight)
    -> string                            4-line text used by the HUD
                                         ("No fight." if nil)

Export(fight)
    -> string  "LF1|id|title|durationSec|damage|dps|healing|hps|taken|
                mitigated|critRate|abilityId:damage;abilityId:damage;..."
               (top 10 damage abilities)
    -> ""      when fight is nil

17.18 StatSnapshot  (LF.Stats.GetSnapshot)
    Every stat the client supports, by key:
      maxHealth maxMagicka maxStamina healthRegenCombat magickaRegenCombat
      staminaRegenCombat healthRegenIdle magickaRegenIdle staminaRegenIdle
      spellPower weaponPower weaponAndSpellDamage spellCritical
      weaponCritical criticalChance spellPenetration physicalPenetration
      spellResist physicalResist criticalResistance armorRating attackPower
      mitigation spellMitigation block dodge miss parry healingTaken
      healingDone damageDone damageTaken
    (a key is missing if the game version does not have that stat)
    Resources:
      healthCurrent healthPowerMax magickaCurrent magickaPowerMax
      staminaCurrent staminaPowerMax ultimateCurrent ultimatePowerMax
    Derived:
      spellCritPct weaponCritPct          crit chance 0..100
      spellResistPct physicalResistPct    armor mitigation 0..100
      timestampMs

17.24 TargetEstimate  (LF.Models.GetTargetEstimate)
    name samples relativeSamples confidence(0..1)
    -- when calibrated (samples > 0):
    predictedMitigation     0..1 total damage reduction on that target
    predictedMitigationStd
    predictedDRPct          0..100
    predictedResistance     resistance points
    predictedResistanceStd
    penetrationUsed         your penetration on the last sample
    penetrationToCap        resistance minus that penetration
    missingPenetration      resistance minus your current highest pen
    overPenetratedPct cappedPct   0..1 share of samples
    status   "ok" | "over-penetrated (resistance <= your penetration)"
             | "capped / extra damage reduction"
    -- when only relative data exists (relativeSamples > 0):
    relativeDamageTaken     ratio vs your average target (1 = same)
    relativeToughnessPct    0..100, (1 - ratio) * 100


===============================================================================
 18. INTERNAL FUNCTIONS
===============================================================================
 Called by the logger while logging. You normally never call these, but they
 are public if you want to feed data in yourself.

 Fight recording (all on a Fight object):
   f:RecordOutgoing(cat, result, abilityId, abilityName, graphic, slotType,
                    targetUnitId, hit, overflow, damageType, powerType, now)
                                                       -> nothing
   f:RecordIncoming(cat, result, abilityId, abilityName, graphic, slotType,
                    sourceUnitId, hit, overflow, damageType, powerType, now,
                    isSelf)                            -> nothing
   f:RecordGroup(cat, result, abilityId, abilityName, sourceUnitId, hit,
                 now)                                  -> nothing
   f:RecordEffect(scope, changeType, abilityId, effectName, unitId,
                  unitName, stackCount, iconName, effectType, sourceType,
                  now)                                 -> effect entry
   f:RecordPower(powerType, value, maxValue, now)      -> nothing
   f:RecordBossHealth(unitTag, name, current, max, now) -> nothing
   f:RecordCast(slotIndex, abilityId, now)             -> kind string
   f:RecordBarSwap(activePair, now)                    -> nothing
   f:RecordDeath(unitTag, unitName, now, recap)        -> DeathEntry
   f:RecordGearChange(slotIndex, now)                  -> nothing
   f:NoteUnit(unitId, name, unitType)                  -> {name, type} | nil
   f:PushEvent(rawEvent)                               -> nothing
   f:CloseOpenIntervals(now)                           -> nothing
   f:Finish(endMs?)                                    -> nothing

 Per-fight trackers:
   LF.Stats.BeginTracking(f) -> nothing   LF.Stats.Sample(f, snap?) ->
   StatSnapshot | nil   LF.Stats.FinishTracking(f) -> nothing
   LF.Sets.BeginTracking(f) -> nothing    LF.Sets.Attribute(f, abilityId,
   name, cat, amount, isActivation) -> setId | nil
   LF.Sets.FinishTracking(f) -> nothing
   LF.Procs.BeginTracking(f) / ObserveCombat(...) / ObserveEffect(...) /
   FinishTracking(f) -> nothing

 Model feeding:
   LF.Models.ObserveOutgoing(abilityId, result, hit, damageType, targetName,
                             targetType, isCrit, isTick)   -> nothing
   LF.Models.ObserveIncoming(abilityId, result, hit, damageType, sourceName,
                             isCrit)                       -> nothing
   LF.Models.ObserveUnitHealth(key, name, current, max, tSec) -> nothing
   LF.Models.ObserveDPS(dps)                               -> nothing
   LF.Models.ResetFightTransient()                         -> nothing
